Examples
========

Example programs demonstrating Fenix usage can be found in the ``examples/`` directory
of the repository.

The examples cover:

* **01_hello_world**: Basic Fenix initialization and finalization
* **02_send_recv**: Point-to-point communication with fault tolerance
* **03_reduce**: Collective operations with fault tolerance
* **04_Isend_Irecv**: Non-blocking communication
* **05_subset_create**: Data subset operations
* **06_subset_createv**: Vector-based subset creation
* **07_resizeable_member**: Resizable data members
* **08_inline_recovery**: Inline recovery patterns

See the source code in ``/projects/examples/`` for complete implementations.
